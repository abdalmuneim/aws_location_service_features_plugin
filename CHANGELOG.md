## 0.2.0

* First version, extracted from the Location Studio app (now `example/`).
* Maps, Places and Routes (v2) over REST with an API key on Android, iOS and the web.
* `AwsMapView` (MapLibre) with a declarative `MapOverlay`.
* On-device geofencing and device location, simulated trips.
* Cloud tracking to Amazon Location trackers: Amazon Location Mobile Auth and
  Tracking SDKs on Android (Kotlin) and iOS (Swift Package Manager), Dart
  (Cognito + SigV4) on the web.
* `AwsLocation` entry point; `Result`-based API with translatable failure codes.
